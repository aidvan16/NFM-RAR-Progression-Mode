# NEED FOR MADNESS 2: REVISED AND RECHARGED: PROGRESSION EDITION

NFM 2 RAR: PROGRESSION is a heavily modified and expanded version of Need For Madness 2 made by Ryan Albano, and Modified by myself! (Aidvan)

his version expands the original game with a full progression system, new and reworked stages, additional vehicles, custom AI behavior, rebalanced cars, new challenges, and a much larger endgame.

## Features

- 70 stages
- 40 playable vehicles
- A full campaign progression system
- Cars unlock as the player progresses
- New and modified tracks
- New boss encounters
- Custom AI behavior for certain stages and vehicles
- Race-only and waste-only stages
- Rebalanced vehicle stats
- New late-game vehicles
- New environmental effects and stage gimmicks
- Expanded post-original-game campaign
- Saving and progression support
- Original Need for Madness 2 cars and stages are still included


The later stages are designed to become increasingly more difficult, introducing wasters such as TURBO TANK and KILL-O-MATIC, 
racers such as Over==Kill and The Awesome Radical One, and good all around vehicles such as Nuclear Warhead, and The Destroyer.

## How to Run

### Requirements

- Windows
- Java Development Kit 6 (JDK 6) [Download Java 6 from the official Oracle archive](https://www.oracle.com/java/technologies/javase-java-archive-javase6-downloads.html)
- Tested with Java 6 Update 45 (`jdk1.6.0_45`) https://www.oracle.com/java/technologies/javase-java-archive-javase6-downloads.html

This game uses the legacy Java Applet Viewer included with JDK 6.

### Starting the Game

1. Download and extract the entire game folder.
2. Make sure **JDK 6 Update 45** is installed.
3. Keep all game files and folders in their original locations.
4. Double-click:

   `Play Game.exe`

5. Need for Madness 2: Revised and Recharged should launch automatically.

### If the Game Does Not Launch

The launcher expects Java 6 Update 45 to be installed at:

`C:\Program Files (x86)\Java\jdk1.6.0_45\`

If Java is installed somewhere else, the launcher may not be able to find it.

The game can also be launched manually from Command Prompt with:

```bat
"C:\Program Files (x86)\Java\jdk1.6.0_45\bin\appletviewer.exe" -J-Djava.security.policy==nfm.policy Game_Scaled.html
```
